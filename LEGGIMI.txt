CAMPANIA SERVICE — VERSIONE CORRETTA

COME AGGIORNARE IL SITO SU GITHUB
1. Estrai lo ZIP sul computer.
2. Apri il repository michelefeola-prog/campania-service su GitHub.
3. Seleziona Add file > Upload files.
4. Carica nella radice del repository i 6 file HTML, style.css e script.js.
   Sostituisci quelli esistenti mantenendo esattamente i nomi.
   Le immagini sono le stesse: non occorre ricaricarle se già presenti.
5. Conferma con Commit changes sul branch main.
6. Attendi il completamento di GitHub Pages, poi aggiorna il sito.
   Se vedi la vecchia versione, premi Ctrl+F5.

Non caricare lo ZIP come singolo file e non creare una sottocartella:
index.html deve restare nella radice, accanto a style.css e script.js.
